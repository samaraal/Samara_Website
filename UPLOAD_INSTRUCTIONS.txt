Samara Public Website v2.3.5 – Gentle Tap Mobile Menu Fix

Replace the supplied files in the same locations in the website repository:
1. All supplied .html files in the repository root
2. js/app.js
3. css/style.css

Reason for fix:
The old code attached BOTH touchend and click to the hamburger button.
A normal mobile tap fired both events, opening and immediately closing the menu.
The touchend handler has now been removed. A single gentle tap opens the menu.
Tapping any menu item navigates normally and closes the menu.
